# Bayesian-Inference-Project
Application of Bayesian inference with data augmentation to model seabird migration between two islands over time. Using Gibbs sampling, it estimates key parameters such as the initial population proportion and migration probability, and analyses posterior uncertainty through trace plots and distributions.
